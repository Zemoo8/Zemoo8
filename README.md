## Highlights

- **Radar target tracking.** A Kalman filter written from scratch in NumPy cuts position error from 63.0 m to 31.1 m (-50.7%) over 15 Monte-Carlo missions, validated against the theoretical sensor error (63.0 m measured vs 62.7 m expected). Includes derivations, CI and a written report.
- **AI Eyes.** A mobile accessibility app for blind and low-vision Arabic speakers in Tunisia: object detection (YOLOv8), Arabic/French OCR and spoken scene description, backed by FastAPI services and a family web dashboard.
- **Data pipeline.** Scraping, cleaning, SQLite storage and a Streamlit analytics dashboard.

## Currently working on

- Extending the radar project toward EKF / IMM estimators with NEES/NIS consistency tests and learned noise models (roadmap is in the repo README).
- Model evaluation and deployment practices: reproducible experiments, metrics and clean architecture.
